# Markerup Privacy Policy

**Effective date: August 22, 2026**

Markerup is a filesystem-first Markdown notes application. This policy explains
what information Markerup collects and how it handles information when you use
the application.

## Information Markerup collects

Markerup does not collect personal information, usage analytics, advertising
identifiers, telemetry, crash reports, or account credentials for transmission
to the Markerup developers. Markerup does not include advertising or behavioral
tracking.

Notes, folders, and other files remain in the workspace location you choose.
For an ordinary local workspace, Markerup reads and writes those files on your
device. For an SMB workspace, Markerup communicates with the server you
provide, using the credentials and remote path you enter, to perform the file
operations you request.

SMB credentials are not written into Markdown files or ordinary application
preferences. On iOS, saved SMB passwords are stored in Apple Keychain. On
platforms where secure persistent storage is unavailable, credentials may be
kept only for the current session.

## Data retention and deletion

Markerup does not maintain a separate cloud copy or proprietary notes
database. Your notes and organization are retained by the local filesystem or
SMB server that you selected. To delete that content, delete the relevant
files from that workspace using Markerup or another file-management tool.

You can remove a saved workspace or disconnect it from Markerup at any time.
Removing the app also removes its local application data according to the
platform’s normal app-removal behavior; Keychain items may require separate
removal by the operating system or a Keychain-management action.

## Third-party services and handling

Markerup does not send your notes or credentials to the Markerup developers or
to an analytics, advertising, or synchronization service. The operating system
and the storage provider you choose necessarily handle the file and network
operations you request. Your SMB server and network provider may retain their
own access logs under their own policies.

This policy is published using GitHub Pages. Visiting this page may be subject
to GitHub’s own privacy and operational policies. Markerup does not control
GitHub’s handling of requests to this website.

## Changes to this policy

If Markerup’s data practices change, this policy will be updated before or when
the change takes effect. The effective date above identifies the current
version.
